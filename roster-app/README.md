# 직원 로스터 관리 프로그램 (프로토타입)

OR-Tools CP-SAT 기반으로 근무 스케줄을 자동 생성하는 웹앱입니다.

## 실행 방법

```bash
cd backend
pip install -r requirements.txt
python app.py
```

브라우저에서 `http://localhost:5000` 접속.

## 구조

```
roster-app/
├── backend/
│   ├── app.py         # Flask API 서버
│   ├── scheduler.py   # CP-SAT 스케줄링 엔진 (핵심 로직)
│   └── requirements.txt
├── frontend/
│   └── index.html     # 단일 페이지 UI (직원/요건 관리, 스케줄 결과 표시)
└── data/
    └── state.json      # 직원/요건/최근 스케줄 저장 (자동 생성됨)
```

## 지금 구현된 것

- 직원 등록/삭제 (이름, 스킬, 주당 최대 근무시간)
- 요일×교대별 필요 인원 및 필요 스킬 설정
- 하드 제약: 하루 1교대, 사용 불가일 제외, 스킬 매칭, 주당 최대시간, 최소 휴식시간(야간 후 연속 근무 금지)
- 소프트 제약: 선호 근무 반영, 야간/주말 근무 공정성 분산
- 요건을 못 채우는 경우 "완전 실패"가 아니라 부족분(shortfall)을 보여주고 이유를 설명

## 알려진 제한사항 (다음에 개선할 부분)

- 이번 주 한 번 생성하는 방식이며, 부분 재배정(직원 결근 시 최소 변경)은 아직 없음
- 선호도는 (요일, 교대) 단위만 지원 — 우선순위 가중치는 아직 단일 값
- 인증/권한(관리자 vs 직원 로그인)은 없음 — 로컬 단일 사용자 프로토타입
- ortools는 이 대화 환경(샌드박스)에서 설치·실행 테스트가 불가능했습니다 (네트워크 차단).
  로컬에서 `pip install ortools` 후 직접 확인해주세요. 문제가 있으면 알려주시면 바로 고쳐드립니다.
